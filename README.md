# Library Management System

## Project Description
The Library Management System is a console-based Java application developed using Java, JDBC, and MySQL. The system allows users to manage library book records efficiently through CRUD (Create, Read, Update, Delete) operations. It provides a menu-driven interface for adding, viewing, searching, updating, and deleting books while storing data in a MySQL database.

## Technologies Used
- Java
- JDBC (Java Database Connectivity)
- MySQL
- SQL
- IntelliJ IDEA
- Object-Oriented Programming (OOP)

## Features
- Add new books to the library
- View all available books
- Search books by ID or title
- Update book details
- Delete book records
- Menu-driven console interface
- Secure database operations using PreparedStatement
- MySQL database integration

## How to Run

### Prerequisites
- Java JDK installed
- MySQL installed and running
- IntelliJ IDEA (or any Java IDE)

### Steps
1. Create a MySQL database.
2. Create the required books table.
3. Update database username and password in the Java code.
4. Open the project in IntelliJ IDEA.
5. Compile and run `LibraryManagement.java`.
6. Use the menu options to perform library operations.
